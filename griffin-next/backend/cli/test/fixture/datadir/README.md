# `db verify` CI fixture

A minimal JSON data dir covering every projected namespace, used by the
datastore CI gate:

```
griffin db backfill --data-dir <this dir>
griffin db verify   --data-dir <this dir>
```

`verify` must report zero drift. It is the only mechanism that catches a new
`Storage` write path silently skipping projection — the most likely way shadow
mode rots — so treat a failure here as a real defect rather than a stale
fixture.

`griffin.db` and its WAL files are generated by the run and gitignored; only
the `storage/` JSON tree is committed.
